# API Documentation

## REST Endpoints
- `GET /api/health` - Health check
- `GET /api/v1/ships` - List ships
- `GET /api/v1/ships/{id}` - Ship details
- `GET /api/v1/ships/{id}/track` - Live tracking
- `GET /api/v1/cargo` - List cargo
- `GET /api/v1/stations` - List stations
