# ML Architecture

## Models
1. **XGBoost**: Primary predictive model (ETA, Cargo Delay, Inventory Shortage, Operational Risk)
2. **LightGBM**: High-volume tabular forecasting (Demand prediction)
3. **Isolation Forest**: IoT anomaly detection (Equipment sensors)
4. **Autoencoder**: Complex multivariate sensor anomaly detection
5. **Survival Analysis**: Remaining Useful Life (RUL) / failure-risk
6. **Graph/Knowledge Graph**: Dependency and cascading impact analysis
7. **OR-Tools**: Constraint optimization (routing, cargo allocation)

*Note: Random Forest is strictly excluded from the predictive ML stack.*
